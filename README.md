# 9544 Applied Geoinformatics (IECS M.Sc.), WS 2026/27

> **Python does the work, PostGIS keeps the data, QGIS lets you see, check and interact.**

This repository holds the notebooks and small files for the course. New material appears session by session in the folders `sNN_date` (for example `s01_2026-10-05`). The course plan at the bottom (schedule, topics, competences and the material released so far) is updated with every release.

## What you will do

You build data pipelines with Python, store and query the results in PostGIS, and use QGIS to inspect, select, digitize and present. Over the semester you will work with:

- open data pipelines (DWD station data via HTTPS, pandas, GeoPandas, GeoPackage, web maps)
- coordinate reference systems in code (pyproj) and georeferencing
- GNSS/RTK measurements and drone flights on campus (RGB, thermal and multispectral data), processed with WebODM
- airborne laser scanning and NRW terrain tiles: scraping, automated download, mosaics, hillshade
- relational databases and PostGIS: spatial SQL, indexes, normalization of real data (OpenHygrisC groundwater)
- spatio-temporal data and QGIS Temporal Controller animations
- remote sensing (Sentinel-2 via STAC, drone indices), land-use classification with scikit-learn
- point clouds, cartography and communicating results

## How a session works (Mondays, 180 minutes)

Retrieval quiz on the last session, two homework presentations, short input, live coding (predict before you run), break, exercise in pairs, debrief, exit ticket. Plan about 7 hours per week of self-study in total; homework takes 2 to 3 hours and the rest goes into your project.

**Task sheets.** Every activity has a task sheet (`geoCCSA_Title.md`) in the session folder, and every notebook explains itself in its text cells. They hold all steps, hints, checks and the homework, often more than there is time to say in class. Read them before you ask, and come back to them when you are stuck. If you do not finish a guided demo or an exercise in class, complete it at home with the task sheet: the homework and the next session build on it.

## Working with this repository

1. **Open the session link in Moodle.** It logs you in to the JupyterHub and puts the repository into your home folder (`~/iecs9544-ws2026`). The same kind of link works every week.
2. **Your changes are kept.** If you edit a notebook and I later update it, your version is not overwritten. For larger experiments, copy a notebook first (for example into a `work/` folder).
3. **Released notebooks do not change silently.** Corrections come as a new file (`..._fix1.ipynb`) or as an entry in `errata.md`.
4. **Data are provided, not downloaded by hand.** Shared data are on the hub (read-only under `~/shared/data`). Notebooks that download data write to a folder outside this repository.
5. **Solutions** are published after the homework deadline, not in this repository.
6. **Working on a laptop (QGIS)?** Clone this repository once (`git clone https://github.com/EOLab-HSRW/iecs9544-ws2026`, or *File → Clone repository* in GitHub Desktop) and `git pull` for updates. The clone is your working folder; there is no need to copy anything out. Never save over a released file: use *Save As…* and add `_mine` or `_my` to the name (e.g. `geo0241_Georeferencing_Castra_Vetera_mine.qgz`). Git ignores these names, and files you create under new names are left alone too, so `git pull` always works. Large open data you download yourself go once into `data/` at the top of the clone (ignored by git; QGIS projects use `../data/`).

### Learning outcomes of the module (module handbook)

After the module you can:

- **LO1**: explain core geoinformatics concepts and the space-time dynamics of environmental data, with a focus on climate change (C1.1, C1.2)
- **LO2**: acquire, manage, and analyze open geospatial datasets from German and international sources, applying data engineering techniques for cleaning and transformation (C2.1, C2.2)
- **LO3**: design and execute integrated geospatial workflows, including data acquisition, processing, analysis, and visualization, using open-source tools (C3.1, C3.2, C3.3)
- **LO4**: create remote sensing products from satellite and drone imagery, including land use classifications and environmental monitoring using machine learning techniques (C4.1, C4.2)
- **LO5**: critically assess the assumptions, limitations, and implications of spatial analysis methods in environmental and climate data contexts (C5.1)
- **LO6**: apply problem-solving and analytical skills to address complex environmental and geospatial challenges in collaborative and interactive project settings (C6.1)
- **LO7**: communicate geospatial findings effectively to technical and non-technical audiences (C7.1)

### Assessment

It must show the four core competences C3.2, C5.1, C6.1 and C7.1 and at least two further competences, depending on your topic.
